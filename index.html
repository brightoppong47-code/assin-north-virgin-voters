Reset system data

This removes every registration/transfer record and every polling station from this Firebase project. All admins and agents see the removal. Electoral areas, user profiles and Firebase login accounts stay in place.

Use Chrome for downloads. Before proceeding, download a backup under Backup & restore and confirm the JSON file is saved. Pause data collection while resetting. Missing data can be recovered using that backup.

Preview the current database first.

If a reset is interrupted, the app pauses new database entries. Wait two minutes after an interruption, then an admin can preview again and finish the remaining reset. Logins stay available.
